`.gitignore`仅作补充防护。实际发布采用CSV白名单逐路径暂存，并运行：

```powershell
.\.venv\Scripts\python.exe -B scripts/verify_public_release.py
.\.venv\Scripts\python.exe -B scripts/verify_public_release.py --check-index
git diff --cached --check
```

保护规则额外覆盖IDE配置、许可/私钥、pickle、Office、DEM、图片及压缩文件。历史patch有合法的空白上下文语法，`.gitattributes`只对这两份历史patch关闭空白检查；普通Python、文档等仍检查行尾空白，保留源字节不自动换行转换。

未获公开确认的原始数据、论文、图片、模板和工作簿继续排除；不能通过改扩展名/子目录绕过白名单。未来新增图像、数据、LICENSE或改动文件应重新核验范围和哈希，不使用`git add .`替代审核。

扫描不能证明任意无固定格式的秘密绝对不存在，也不是第三方权利的法律证明。结论适用于本次实际核验的文件快照；本地环境、日志和审计脚本不在公开范围，不能打包整个目录上传。
