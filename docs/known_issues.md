# 已知问题与复现边界

本文记录论文表述、实际代码与历史实验之间的差异，以及尚未完成的验证。整理阶段保留数学模型、正式参数和搜索逻辑，不用文档改写掩盖这些差异，也不以修复问题为由覆盖冻结结果。正式版本见 [formal_versions.json](formal_versions.json)，运行边界见 [running.md](running.md)，实验分类见 [experiments/README.md](../experiments/README.md)。

## 1. 模型与目标口径

| 编号 | 已核对的差异或限制 | 对解释与后续工作的影响 |
|---|---|---|
| K01 | Q2 论文给出 min-max 归一化一般式；`problem2_alns_improved.py` 实际按固定参考尺度计算 `Zk / sk`。`s1` 来自货箱优先系数与期望时间乘积之和，其他尺度来自 Q1 种子解码，并带数值下界保护 | 文档按实际实现说明。若改为 min-max，会改变目标评价和搜索轨迹，须作为另一个明确实验，不能作为工程修复 |
| K02 | Q2 论文的 Z1 求和排除首批保障货箱；正式代码对全部已配送货箱累加“优先系数 × 超出期望时刻的秒数”，硬截止可行性另行检查 | 两种求和集合不能在未经论证时视为完全等价。归档正式 Z1=0 只能说明该归档解的代码指标，不能证明一般等价 |
| K03 | NSGA-II 的 `evaluate_objectives()` 仅对没有硬截止条件的货箱累加 Z1，与正式 ALNS 的范围不同 | 不直接比较 Z1 或据此给出算法排名；未来比较需先明确指标口径和预算，保留当前实现与归档 |
| K04 | Q3 通信检查依赖数值采样和状态边界细化；LEVEL1 是搜索评价，不能替代最终 LEVEL2 标准检查 | 归档“未覆盖时长为0”和13项 PASS 是原检查精度下的结果，不是任意连续时刻通信成立的解析证明。Phase 3 读取了标记，没有重新执行完整通信审计 |
| K05 | Q4 固定 Q3 运输与中继时序，通过任务块分区和资源核算比较独立任务组；分区可能复制中继任务 | K2-032/K3-007 的整体完工时间仍为 6985.31006777659 s，不能宣称分区缩短工期。两方案均有运输 UAV、电池和中继 UAV 库存缺口，不是现有库存下已全部可执行的方案 |

## 4. 验证结论的边界

Phase 3 已验证15项轻量测试、41个模块导入、36份冻结正式结果的完整性，以及 Q4 的1008项资源计数。Gurobi 通过了小规模真实建模函数检查，没有执行完整集合划分优化；模型可创建不等于任何机器都有适用完整实验的许可证。

尚未完成的工作包括 Q1 完整候选与三阶段求解、Q2 正式1000次及扩展搜索、Q3 ALNS/VNS和完整通信重审、Q4完整枚举、完全空白环境安装及跨系统验证。现有虚拟环境复用了本机科学计算依赖。Phase 4 的回归和文档检查结果另见 [phase4_report.md](phase4_report.md)，不能外推为完整优化复现。

正式结果中的 `OPTIMAL`、`PASS` 和耗时均保留归档语境。优化结果汇总、轻量复核及完整重新求解应分别标注；没有新实验时，不新增性能提升、显著性或逐步搜索轨迹一致的结论。
