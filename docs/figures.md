# 图片来源与展示候选

当前没有将原论文或实验图片复制到公开候选文件中，也没有嵌入指向原竞赛目录的图片链接。图片、DEM 及其派生材料的再分发权限尚未确认；README 先展示已核验的数值表，图片待完成授权与隐私审核后再补充。没有新绘制实验图片，也没有为了配图启动优化。

## 来源依据

本次只读核对了用户确认的最终论文，其来源及 SHA-256 见 [formal_versions.json](formal_versions.json) 的 `paper_basis`。读取 DOCX 的正文题注、`document.xml.rels` 和嵌图关系，同时对原开发目录与 `附件/论文图片集/` 的 PNG 计算 SHA-256。

[figures.csv](figures.csv) 登记 15 张代表图片：来源路径以原竞赛工作目录为基准，仅用于溯源，不是仓库相对链接；`generation_script` 和 `formal_data` 列以发布候选根目录为基准。原始数据来源用 `dependencies.csv` 的依赖 ID 标记。嵌图 `word/media/...` 是论文内部标识，不表示已将论文或图片加入仓库。

DOCX 内图片经过缩放或重新编码，通常与外部 PNG 字节不同。证据分为三类：

- **原图字节对应**：开发目录 PNG 与附件图片的 SHA-256 完全相同。
- **题注与结构对应**：依据最终论文嵌图位置、题注及缩放后的图像结构指纹匹配；不声称逐字节一致，也不代替像素内容审核。
- **目视对应**：本轮实际打开原图及 DOCX 嵌图，比对共享电池图、送达时刻图与 Q4 Pareto 图，确认内容对应。其他图片未逐张完成目视隐私审核。

已扫描附件中的 28 张 PNG 文本元数据；其中 26 张包含 Software 文本元数据，未检出 Windows 绝对路径、邮箱或手机号模式。这只是文本元数据检查，不证明图中不存在个人信息，也不表示拥有公开授权。最终论文存在作者、最后修改者等 Office 元数据，未将其私人值写入本清单。

## 公开前处理

所有登记图片的 `authorization_status` 均为 `pending_review`，`publication_status` 均为 `not_copied`。公开审核需要同时确认图片作者/合作贡献、底层数据或地图的派生使用许可、像素中的个人信息及 PNG/PDF 元数据。来源可追溯与有权再分发是两个独立条件。

授权通过后，可以在另一次明确的发布整理中复制获准图片、记录副本哈希并补充 README 引用。若需脱敏，应生成另有溯源的新展示副本，保留原图及冻结结果；不能覆盖原件。缺失生成脚本的图片仍需说明这一限制。完整待审材料继续见 [review_required.csv](review_required.csv)，本文件没有代替或更改历史审核状态。
