# 新运行输出

Phase 3 已将全部 41 个原有脚本的默认输出接入本目录。推荐通过项目根的 `run.py` 启动，每次创建独立运行子目录；指定 `--run-dir` 时，只接受本目录内尚不存在的目录，拒绝覆盖上次运行。

每次统一入口运行保存 `run_manifest.json`，记录参数、源码和实际输入/输出哈希、环境版本及成功或失败状态。它可能包含本机绝对路径，连同图表、缓存、日志和预备输入默认被 Git 忽略。

正式结果始终保留在 `results/reference/`，只读核验，不能用新结果覆盖。新工作簿与冻结结果数值一致，也不代表文件字节一致。

`--input-dir` 只支持一个输入根，不会自动合并历次运行。连续重算时，应在本目录内另建 `inputs/problemN` 汇集并校验自己生成的中间文件，避免缺项时意外回退至冻结表；示例与验证状态见 [运行说明](../../docs/running.md#从原始输入构建中间依赖)。

Phase 4 仅执行轻量回归与文档检查，没有启动 ALNS/VNS、大规模通信缓存构建或完整分区枚举。运行记录不代表材料已经获准公开。
